One line roasting my own agent, and honestly it earned it: it loves calling things done. It ticked the task off, sent me a tidy report about the doneness, and only then got round to opening the task itself. Anyone who uses one of these daily knows that order of events a bit too well.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` if you set that).
